# 飞书聊天指令

## 已支持

- `帮助`：显示可用指令。
- `状态`：读取本地 SQLite 和 Agent 状态摘要。
- `扫描资料`：运行本地资料扫描脚本。
- `待发布`：列出本地 `publish.json` 中 `ready` 或 `draft_saved` 的任务包。
- `审计批次 5 18`：审计指定编号范围的发布正文和标签质量。
- `同步飞书`：只提示风险，不执行。
- `确认同步飞书`：向飞书 Base 推送本地 SQLite 投影。

## 暂不直接执行

- `生成笔记`：会调用内容生成和生图能力，后续需要加确认卡片。
- `生成二维码`：会触发扫码发布链路，后续需要先确认图片托管和批次质量。
- `部署`：会修改线上服务，必须保留人工确认。
- `发布笔记`：永远不支持自动发布，只能由用户在小红书 App 内审核并点击发布。

## 安全边界

- 不保存小红书账号、Cookie、验证码或密钥。
- 不调用余额为 0 的 myaibot API。
- 不把二维码打开、预览页打开或小红书编辑页打开记为发布成功。
- 写入飞书 Base 的动作必须用明确指令 `确认同步飞书`。
